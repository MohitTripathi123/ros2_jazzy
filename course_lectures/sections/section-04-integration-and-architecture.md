# Section 4: ROS 2 Integration & System Architecture

[Back to course index](../README.md)

## Lecture 19: Mini Integration System: Velocity Controller

Combine a parameterized velocity publisher, runtime validation, namespace, launch file, and YAML configuration. This mini-system demonstrates how previously separate ROS 2 features work together.

## Lecture 20: Clean Package Structure & ROS 2 Best Practices

Organize source code, launch files, configuration, resources, interfaces, and tests predictably. Learn dependency declaration, executable naming, installation rules, and separation of configuration from logic.

## Lecture 21: ROS Graph & System Visualization

Visualize how nodes, topics, services, and actions connect at runtime. Use graph inspection to confirm architecture, discover naming mistakes, and explain data flow through a distributed ROS 2 system.

## Lecture 22: YAML Parameter Files

Move node parameters into YAML files and load them through a launch description. Understand node-key matching, namespaces, `ros__parameters`, override order, and reusable configuration.
