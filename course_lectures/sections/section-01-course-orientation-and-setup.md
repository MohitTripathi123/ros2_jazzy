# Section 1: Course Orientation & ROS 2 Setup

[Back to course index](../README.md)

## Lecture 1: Before You Start Phase 1: How to Learn Core ROS 2 Properly

Understand how the first phase is structured and how to practise ROS 2 effectively. The emphasis is on running every example, observing the ROS graph, and learning the reason behind each command instead of memorising syntax.

## Lecture 2: Course Orientation & Roadmap

Review the complete path from core ROS 2 communication to simulation, navigation, manipulation, perception, and system integration. This lecture explains how the projects and later applied-robotics sections build on the foundations.

## Lecture 3: Installing ROS 2 Jazzy

Install ROS 2 Jazzy and verify that the environment is working. Learn how to source the ROS installation and confirm access to the ROS 2 command-line tools and example packages.

## Lecture 4: Installing VS Code for ROS 2 Development

Prepare Visual Studio Code for Python and ROS 2 development. Configure the editor, terminal, extensions, and workspace so that package files and ROS dependencies can be developed efficiently.

## Lecture 5: Creating Your First ROS 2 Package

Create a ROS 2 Python package and examine its generated structure. Learn the roles of `package.xml`, `setup.py`, the Python module, resource index, tests, and console entry points.

## Lecture 6: Colcon Build System

Build a ROS 2 workspace with Colcon, source the resulting install space, and run an installed executable. Understand the purpose of the `build`, `install`, `log`, and `src` directories.
